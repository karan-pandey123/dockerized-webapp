# Dockerized Web Application Deployment

A production-grade Flask + MongoDB web application showcasing modern DevOps practices with Docker containerization, multi-stage builds, and orchestration.

 Overview

This project demonstrates core Docker and DevOps concepts:
- **Multi-stage Dockerfile** for optimized image building
- **Docker Compose** for multi-container orchestration
- **Isolated bridge networks** for secure container communication
- **Persistent volumes** for data integrity
- **Scalable architecture** ready for production deployment

---

 ✨ Key Features

 ** Containerized Flask Application** - Python web app with MongoDB integration  
 ** Multi-stage Build** - Reduces image size by ~40% using builder pattern  
 ** Docker Compose Orchestration** - Easy multi-container management  
 ** Isolated Networks** - Custom bridge network for service isolation  
 ** Persistent Storage** - MongoDB data survives container restarts  
 ** Professional Frontend** - Responsive form interface with CSS styling
